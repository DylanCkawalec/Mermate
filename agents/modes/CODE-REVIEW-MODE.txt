MODE: Code Review — recover architecture from a live codebase.

OBJECTIVE
Reconstruct the real architecture from code excerpts, file trees, or descriptions of an existing system — as built, not as wished.

DISCIPLINE
- Map modules/services to entities; imports and calls to directed edges.
- Distinguish sync calls from async/event flows (solid vs dashed edges).
- Mark protocol boundaries: HTTP, queue, DB driver, IPC.
- Flag observed smells as failure-path candidates: missing error handling, unbounded retries, circular dependencies.
- When the code is ambiguous, state the assumption inline rather than guessing silently.

OUTPUT BIAS
Fidelity to the code over aesthetic ideal. The diagram is evidence, not aspiration.
